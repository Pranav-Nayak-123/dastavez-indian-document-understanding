Where it breaks

Every mistake was on the harshest images. We read the raw output to find out why.

  1. Single digits get misread. A blurry 3 becomes a 1, a 8 becomes a 6. It does this with full confidence, so check roll numbers.
  2. Years go wrong. 2026 read as 2024 in three dates.
  3. Unreadable labels leave fields empty. When the labels are unreadable the model returns nothing instead of guessing.
  4. The text reader can hallucinate. On one Tamil photo it invented a poem. The field reader, which looks at the image separately, still got the right name.

How it works

Five steps, all handled by Indian-built models from Sarvam AI.

  1. 1

    Upload

    A photo, scan or PDF in any of 22 Indian languages or English.

  2. 2

    Read

    Sarvam Vision reads the page, keeping tables and scripts intact.

  3. 3

    Extract

    The key fields are pulled out: name, ID, date, amount, organisation.

  4. 4

    Understand

    Sarvam‑105B writes the summary and answers questions from the document only.

  5. 5

    Translate

    Sarvam‑Translate converts it line by line. IDs, dates and amounts are never touched.

Built for a brief

CS3235 mini-project, Indian Document Understanding Tool, from the AI4Bharat and BharatGen project list. The brief suggests BharatGen Patram, a 15 GB model with no hosted version, so we used Sarvam's hosted models.

Be careful with

Roll numbers, dates and amounts on blurry photos. The tool can be confidently wrong about a single digit. Always compare with the original.

Privacy

Files are sent to Sarvam AI's servers for processing. Please don't upload sensitive personal documents.
